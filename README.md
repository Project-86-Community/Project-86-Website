# Project 86 Website

The Project 86 game website. GitHub Pages serves the static files from the repository root.

To work on the site locally, open `index.html` or run `python3 -m http.server 8000` in this directory and visit `http://localhost:8000`.

In-game imagery is bundled as WebP. `spearhead.webp`, `plains.webp` and `combat.webp` are from the [Project 86 itch.io page](https://project-86.itch.io/project-86). `morpho.webp` is from the [anniversary release devlog](https://project-86.itch.io/project-86/devlog/1789119/v2xx-alpha-third-year-anniversary-release). The Barlow Condensed and DM Sans font licenses are in `assets/`.
